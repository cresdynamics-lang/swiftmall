# Swifmall

Countrywide multi-category store for [swiftmall.co.ke](https://swiftmall.co.ke) — black, yellow & white, mobile-first.

## Stack

- Next.js (App Router) + TypeScript + Tailwind CSS
- Client cart / saved items (localStorage)
- Sample catalogue from owner product photos
